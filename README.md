# Snake Game

A modern, feature-rich Snake game with a dark theme and multiple gameplay elements.

## Features

- 🎮 Classic Snake gameplay with modern twist
- 🎨 Dark theme interface
- ⚡ Speed control
- 🍎 Multiple food types:
  - Regular food (red)
  - Poison food (black)
  - Bonus food (gold)
  - Speed food (blue)
- 🏆 High score system
- ⭐ Score multiplier system
- 🚧 Obstacles
- 🎯 Increasing difficulty

## How to Play

1. Open `index.html` in your web browser
2. Click "Start Game"
3. Use arrow keys to control the snake
4. Collect food to grow and increase your score
5. Avoid obstacles and poison food
6. Try to beat your high score!

## Controls

- ⬆️ Up Arrow: Move up
- ⬇️ Down Arrow: Move down
- ⬅️ Left Arrow: Move left
- ➡️ Right Arrow: Move right
- Start/Pause: Click "Start Game" button
- Restart: Click "Restart" button

## Food Types

- 🔴 Regular Food: +10 points × multiplier
- ⚫ Poison Food: Game Over if eaten
- 🟡 Bonus Food: +30 points × multiplier
- 🔵 Speed Food: Temporary speed boost

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Canvas API

## Installation

1. Clone the repository:

```bash
git clone https://github.com/your-username/snake-game.git
```

2. Open `index.html` in your web browser
